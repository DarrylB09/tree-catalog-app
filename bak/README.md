# Árboles Nativos - Tree Catalog App

Proyecto para un emprendimiento ecológico enfocado en la promoción y catálogo de árboles nativos.

## Estructura del Proyecto

- `index.html`: Página de inicio.
- `about.html`: Información sobre el emprendimiento.
- `catalog.html`: Catálogo de especies.
- `contact.html`: Formulario y datos de contacto.
- `assets/`: Recursos estáticos (CSS, JS, imágenes, iconos).
- `.gitignore`: Archivos ignorados por Git.

## Cómo empezar

1. Abre esta carpeta en Visual Studio Code.
2. Haz clic derecho en `index.html` y selecciona **Open with Live Server**.
