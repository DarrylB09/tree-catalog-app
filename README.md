# Árboles Nativos - Catálogo y Restauración

Ecosistema digital para la promoción, catálogo y gestión de especies arbóreas nativas. Este proyecto busca facilitar la reforestación y conservación mediante herramientas modernas para propietarios de fincas, proyectos ambientales y comunidades.

## Tecnologías Utilizadas

- **React 19**: Biblioteca para interfaces de usuario.
- **Vite**: Herramienta de construcción rápida para desarrollo frontend.
- **Framer Motion**: Animaciones fluidas y modernas.
- **Lucide React**: Iconografía minimalista.
- **CSS3 (Vanilla)**: Sistema de diseño personalizado con variables.

## Estructura del Proyecto

- `src/pages/`: Páginas principales (Inicio, Sobre Nosotros, Catálogo, Detalle, Contacto).
- `src/components/`: Componentes globales reutilizables (Navbar, Footer).
- `src/sections/`: Secciones modulares de la página de inicio.
- `src/data/`: Archivos de datos (ej. `trees.js` con el catálogo de especies).
- `src/styles/`: Definiciones globales de diseño y variables CSS.

## Instalación y Desarrollo

1. Clona o descarga el proyecto.
2. Instala las dependencias:
   ```bash
   npm install
   ```
3. Inicia el servidor de desarrollo:
   ```bash
   npm run dev
   ```

## Objetivos del Proyecto

1. **Catálogo Digital**: Base de datos consultable de árboles nativos con fichas técnicas detalladas.
2. **Educación Ambiental**: Información histórica y técnica sobre restauración ecológica.
3. **Conexión Directa**: Facilitar el contacto para cotizaciones y asesoría personalizada.
